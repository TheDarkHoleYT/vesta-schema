SECURITY.POLICY.WRITABLE

Configurazione modificabile da utenti non amministratori

Scheda

AreaSecurity
SeveritaCritical

Evento Windows5065 nel log VestaMaintenance

Emesso daSECURITY.POLICY

Che cosa significa

Il file «{Path}» può essere modificato da {Count} identità che non sono amministratori: {Identities}. Quel file decide quali correzioni vengono eseguite con i privilegi di SYSTEM, quindi chi lo modifica ottiene di fatto esecuzione di codice privilegiato su questo computer: gli basta aggiungere una voce e aspettare la manutenzione notturna.

Da dove cominciare

Togliere il permesso di scrittura a chi non è amministratore, sul file e sulla cartella che lo contiene: chi può cancellare il file può rimetterne un altro, e i permessi del file vecchio non contano più. Da riga di comando elevata: icacls «{Path}» /inheritance:r /grant «SYSTEM:(F)» /grant «Administrators:(F)». Se la configurazione sta su una share, guardare anche i permessi di condivisione oltre a quelli NTFS: valgono i più restrittivi dei due, ma spesso la condivisione è aperta a Everyone e nessuno se ne ricorda.

English

Configuration can be modified by non-administrators

File '{Path}' can be modified by {Count} non-administrator identities: {Identities}. That file decides which fixes run with SYSTEM privileges, so whoever can modify it effectively gains privileged code execution on this computer: add an entry, wait for the nightly maintenance.

Generato da build/New-SchemaSite.ps1. Gli identificativi e la loro documentazione sono pubblicati perche' chiunque possa scriverci sopra regole, ticket e correlazioni.
